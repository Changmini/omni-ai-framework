`EventBus.publish`가 구독자 하나 때문에 망가지지 않게 해줘.

- 구독자 하나가 예외를 내도 다른 구독자는 그대로 받는다. `publish`는 예외를 밖으로 내지 않는다.
- 실패한 구독자에게는 처음을 포함해 최대 3번까지 다시 전달한다.
- 3번 모두 실패하면 `dead_letters` 목록에 `{"topic", "payload", "subscriber", "error"}`를 남긴다. `subscriber`는 그 구독 함수, `error`는 마지막 예외를 문자열로 바꾼 것.
- 구독자들은 구독한 순서대로 받는다.
- 시험도 추가할 것.
