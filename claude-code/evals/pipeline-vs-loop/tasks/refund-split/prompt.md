결제된 주문의 환불액을 줄마다 나눠 주는 `OrderService.refund_breakdown(order_id)`를 추가해줘.

- 결제된(paid) 주문만 된다. 아니면 `OrderError`.
- 주문 할인을 줄 금액(단가×수량) 비율로 각 줄에 나눈다. 줄 환불액 = 줄 금액 - 그 줄에 나눈 할인.
- 줄 환불액을 모두 더하면 주문 합계(total)와 정확히 같아야 한다.
- 나누고 남는 원은 나머지가 큰 줄부터 1원씩 더 나눈다(나머지가 같으면 앞 줄부터).
- 반환: 줄 순서대로 `[{"sku": ..., "refund": ...}, ...]`.
- 시험도 추가할 것.
