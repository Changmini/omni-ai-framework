CSV 글로 사용자를 한꺼번에 들이는 `importer.py`를 새로 만들어줘: `import_users_csv(store, text)`.

- 첫 번째 비어 있지 않은 줄이 머리글이다. 머리글에는 `name` 열이 있어야 하고, 다른 열은 무시한다. 머리글 이름은 앞뒤 공백과 대소문자를 무시하고, 열 순서는 아무래도 된다.
- 글 맨 앞의 BOM, 따옴표로 감싼 칸 안의 쉼표를 처리한다. 빈 줄은 건너뛴다.
- 이름이 비었거나 공백뿐인 줄은 잘못된 줄이다.
- 한 줄이라도 잘못되면 아무도 만들지 않고 `ImportReportError`를 낸다. 그 예외의 `errors`는 `[(줄 번호, 사유), ...]`로, 잘못된 줄을 모두 담는다. 줄 번호는 파일 기준 1부터 센다(빈 줄 포함, 머리글이 1이면 1).
- `name` 열이 없으면 머리글 줄 번호로 같은 예외를 낸다.
- 성공하면 만든 사용자 id 목록을 순서대로 돌려준다.
- 시험도 추가할 것.
