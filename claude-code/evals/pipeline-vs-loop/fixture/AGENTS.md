# sample-app

메모리에 사용자·재고·가격·주문을 두는 작은 쇼핑 예시 앱입니다(표준 라이브러리만).

## 규칙

- 사용자 데이터를 바꾸는 동작(생성·수정·삭제)은 모두 `UserStore.audit`에 `{"action": <동작>, "user_id": <id>, "at": <시각>}` 한 항목을 남긴다.
- 시각은 `_now()`(주문은 주입된 `clock`)로만 만든다(UTC ISO 8601, `Z`로 끝남).
- 금액은 원 단위 정수다. float으로 계산하지 않는다.
- 주문 상태가 바뀌면 `events.publish("order.<새 상태>", {"order_id": <id>})`를 한 번 부른다.
- 이미 있는 공개 함수의 인자와 반환 모양은 바꾸지 않는다(새 인자는 기본값과 함께 뒤에).
- 시험: `python3 -m unittest`
