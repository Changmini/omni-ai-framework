      이 그림을 Claude가 참고하는 방법

      자동
      • [Claude에게 알리기] 켬 → 그림의 구성·메모를 연결된 터미널의 Claude에게 전달
      • 그 터미널에서 질문을 보낼 때 함께 감
      • 그림이 바뀌었을 때만 다시 감
      • Claude를 새로 켰거나 대화가 요약된 뒤에도 한 번 더
      직접 요청
      • Claude 입력창에 /omni:pipeline 입력
      • 또는 "다음 단계가 뭐야?"처럼 물어보기
      • 켬·끔과 관계없이 그때 전달
      전하는 내용
      • 연결된 상자(노드)의 이름·메모
      • 화살표로 바로 앞뒤 상자의 이름·메모
      • 그 상자들에 연결된 Claude의 이름
      잠시 빼기
      • 상자 우클릭 → [알리기에서 잠시 빼기]
      • 그 터미널에는 보내지 않음
      • 다른 터미널에는 「잠시 빠짐」으로만 알림
      사용량
      전달될 때만 토큰 사용 (한 번에 수백 자)
      대상
      이 앱의 터미널에서 실행한 Claude만

      최근 활동

        Claude가 이 터미널에서 일하면 프롬프트, 도구 실행, 수정한 파일이 여기에 쌓입니다.
